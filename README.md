<h1 align="center">X Tube</h1>
<p align="center">Free AI toolkit for YouTube creators — a Chrome extension that needs only a Google AI Studio key.<br>
افزونهٔ رایگان کروم برای یوتیوبرها؛ فقط به کلید Google AI Studio نیاز دارد.</p>

## Features | امکانات
- **Side panel**: smart titles, description writer, keyword research, chapters, video audit, thumbnail review.
- **Tags window** on every YouTube video page.
- **YouTube Studio assistant**: better titles and tags as you type, one-click insert, Refresh for new ideas.
- **Chapter generator** with fallbacks (pasted text → captions → Gemini video analysis).
- Light / dark / system theme. Your key stays in your browser.

## Install | نصب
1. Download `XTube-vX.Y.Z.zip` from [Releases](../../releases/latest) and extract it.
2. Open `chrome://extensions` → enable **Developer mode**.
3. **Load unpacked** → select the extracted folder.
4. Click the X Tube icon (or `Alt+Shift+T`) → **Settings** → paste a free key from <https://aistudio.google.com/apikey>.
