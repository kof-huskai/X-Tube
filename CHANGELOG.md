# Changelog

## 3.0.0
- Rebranded as **X Tube** with new logo and red/black/white theme.
- Side panel with tabs: Titles, Description, Keywords, Chapters, Video audit, Thumbnail.
- Floating tags window on YouTube watch pages.
- YouTube Studio assistant: live title and tag suggestions, one-click insert, Refresh.
- Chapter generator with fallback cascade (pasted text, captions, Gemini video analysis).
- Light / dark / system themes, themed scrollbars, tab-strip arrows and wheel scroll.
- Only a Google AI Studio key is required.
